# deepseek-harness-releases

这个仓库只发布 DeepSeek Harness 分支的自用 Windows 安装包。

这里没有源代码。请从 [Releases](https://github.com/Apoil/deepseek-harness-releases/releases) 下载安装包。已安装应用里的检查更新也读取这些 Release。

This repository publishes personal Windows installers for a DeepSeek Harness fork.

It contains no source code. Download installers from [Releases](https://github.com/Apoil/deepseek-harness-releases/releases). The installed application's update check reads those releases.
